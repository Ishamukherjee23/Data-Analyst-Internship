# Task 5 - Exploratory Data Analysis (EDA)

## Objective
To perform Exploratory Data Analysis (EDA) on the Titanic dataset and identify important patterns, relationships, trends, and anomalies.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Titanic Dataset

## Analysis Performed
- Dataset inspection
- Descriptive statistics
- Missing value analysis
- Value counts
- Histogram
- Boxplot
- Scatterplot
- Correlation heatmap
- Pairplot
- Univariate analysis
- Bivariate analysis
- Multivariate analysis

## Data Cleaning
Missing values in the `age` column were handled using the median value, while missing values in the `embarked` column were handled using the mode.

## Key Findings
1. Female passengers generally had a higher survival rate than male passengers.
2. Passenger class had a noticeable relationship with survival.
3. Higher-class passengers generally had better survival outcomes.
4. The fare distribution contained some potential outliers.
5. The scatterplot was used to explore the relationship between age and fare.
6. The correlation heatmap showed relationships among numerical variables.
7. Pairplot helped visualize relationships between multiple numerical variables.
8. Multivariate analysis showed the combined effect of passenger class and gender on survival.

## Conclusion
Exploratory Data Analysis was successfully performed on the Titanic dataset using Python. Statistical analysis and visualizations helped identify important patterns, relationships, and potential anomalies in the dataset.
