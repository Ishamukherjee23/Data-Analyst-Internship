# Task 4 - Dashboard Design

## Objective
To design an interactive dashboard for analyzing sales and financial performance using Power BI.

## KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Sales Growth

## Analysis
- Sales Trend Over Time
- Sales by Category
- Sales by Region
- Profit by Segment

## Interactive Filters
- Region
- Category
- Segment

## Tools Used
- Microsoft Power BI
- Microsoft PowerPoint

## Dashboard
The dashboard provides an interactive view of sales and financial performance.
