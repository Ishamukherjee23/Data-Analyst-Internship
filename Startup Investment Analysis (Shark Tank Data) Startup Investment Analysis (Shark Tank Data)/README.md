# Startup Investment Analysis

##  Project Overview

This project analyzes Shark Tank India startup investment data to identify investment trends across different industries and investors.

The analysis was performed using Microsoft Power BI to create an interactive dashboard and visualize startup investment patterns.

##  Objectives

- Analyze startup investment trends.
- Study investment distribution across different industries.
- Identify the number of startups in different industries.
- Identify the top 10 startups based on investment amount.
- Analyze investment according to the number of participating sharks.
- Analyze industry-wise investor investment trends.
- Analyze deal acceptance patterns.

##  Dataset

The project uses a Shark Tank India dataset in CSV format.

The dataset contains information related to:
- Startup names
- Industries
- Deal amounts
- Investor investment amounts
- Number of sharks
- Accepted offers

##  Tools Used

- Microsoft Power BI
- CSV / Microsoft Excel
- Microsoft Word

##  Dashboard

The Power BI dashboard contains:

1. Total Startups
2. Total Investment
3. Average Investment
4. Investment by Industry
5. Number of Startups by Industry
6. Top 10 Startups by Investment
7. Investment by Number of Sharks
8. Industry Filter

##  Analysis Pages

### Main Dashboard
Provides an overall view of startup investment activity.

### Investor Analysis
Shows industry-wise investment contributions from different investors.

### Deal Success Analysis
Analyzes accepted deals by industry and overall deal acceptance status.

##  Key Results

- Total startups analyzed: **789**
- Total investment shown in the dashboard: **34.82K**
- Average investment: **80.24**
- Accepted offers represented in the acceptance analysis: **434**
- Non-accepted offers represented in the acceptance analysis: **68**

##  Dataset Limitation

Founder-specific information was not available in the selected dataset. Therefore, a direct founder-level success analysis could not be performed.
