# Task 3: SQL for Data Analysis

## Objective
The objective of this task is to use SQL queries to extract, manipulate, and analyze structured data from an e-commerce database.

## Tool Used
- SQLite
- Programiz Online SQL Editor

## Dataset
The existing e-commerce dataset provided in the Programiz SQL environment was used for this task.

### Tables Used
- Customers
- Orders

## SQL Concepts Used
The following SQL concepts were implemented:

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- INNER JOIN
- LEFT JOIN
- Aggregate Functions
  - SUM()
  - AVG()
  - MAX()
  - MIN()
  - COUNT()
- Subqueries
- HAVING
- Views
- Indexes

## Analysis Performed
1. Retrieved customer and order information using SELECT.
2. Filtered records using WHERE.
3. Sorted records using ORDER BY.
4. Grouped data using GROUP BY.
5. Combined customer and order data using INNER JOIN and LEFT JOIN.
6. Calculated total revenue using SUM().
7. Calculated average order value using AVG().
8. Identified the highest-value order using a subquery.
9. Calculated customer-wise spending.
10. Counted the number of orders per customer.
11. Used HAVING to filter grouped results.
12. Created a view for customer order details.
13. Created indexes to improve query performance.

## Files Included
- `task3.sql` - Contains all SQL queries used for the analysis.
- `screenshots/` - Contains screenshots of the SQL query outputs.

## Outcome
This task helped in understanding how SQL can be used to retrieve, filter, join, aggregate, and analyze structured e-commerce data efficiently.

## Conclusion
The task provided practical experience with SQL data analysis techniques, including joins, aggregate functions, subqueries, views, and indexes.
